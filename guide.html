Chrome Extension Guide

Cookie Editor & Storage Manager

Control cookies, localStorage, and sessionStorage from one side panel. Edit faster, clean data safely, and migrate storage with JSON import/export.

Quick Start

  1. Open any website tab where you want to inspect storage.
  2. Click the extension icon to open the side panel.
  3. Choose Cookies, LocalStorage, or SessionStorage tabs.
  4. Search, expand rows, edit, delete, or add new entries.

Core Features

  • Inline edit for cookies and web storage values.
  • Delete single entries or delete all for the active section.
  • JSON export with type selection (cookies/local/session).
  • JSON import merges only the exported storage types.
  • Validation and custom alerts for safe operations.

Import and Export Model

Export files include a selectedTypes field. Import uses that field to decide what to apply. 

{
  "selectedTypes": ["cookies", "localStorage"],
  "cookies": [ ... ],
  "localStorage": [ ... ]
}

If sessionStorage is not selected at export time, import will not touch it.

Best Practices

  • Use export before large cleanup tasks.
  • Review domain/path when editing cookie identity fields.
  • Keep imported JSON generated by this extension format.
  • Use search filters before bulk actions to avoid mistakes.
